# Версии плагина Reckue Languages

## 📋 Доступные версии

### 🔗 API Version (0.5.7-api)
**Имя:** Reckue Languages (API)  
**Описание:** Версия с синхронизацией через API reckue.com

**Особенности:**
- ✅ Автоматическая авторизация через temp-in
- ✅ Синхронизация словарей с сервером
- ✅ Облачное хранение прогресса
- ✅ Мультиустройственная поддержка
- ✅ Fallback на локальное хранение

**API Endpoints:**
- `https://api.reckue.com/api/1/auth/tempin`
- `https://api.reckue.com/api/1/wordbooks`
- `https://api.reckue.com/api/1/wordbook/words/*`

### 💾 Local Version (0.5.7-local)
**Имя:** Reckue Languages (Local)  
**Описание:** Версия с локальным хранением в localStorage

**Особенности:**
- ✅ Локальное хранение данных
- ✅ Работа без интернета
- ✅ Быстрая работа
- ✅ Приватность данных

## 🔄 Переключение между версиями

### Проверка текущей версии
```bash
./check-version.sh
```

### Переключение на API версию
```bash
./switch-to-api.sh
```

### Переключение на локальную версию
```bash
./switch-to-local.sh
```

## 📦 Сборка

### API версия
```bash
npm run build:api
```

### Локальная версия
```bash
npm run build
```

## 🔍 Как определить версию

### В браузере
1. Откройте `chrome://extensions/`
2. Найдите плагин "Reckue Languages"
3. Посмотрите на имя и версию

### В коде
```bash
# Проверка версии в package.json
grep '"version"' package.json

# Проверка версии в manifest.json
grep '"version"' manifest.json

# Проверка имени плагина
grep '"name"' manifest.json
```

### Автоматическая проверка
```bash
./check-version.sh
```

## 🚀 Рекомендации

### Используйте API версию если:
- У вас несколько устройств
- Важна синхронизация данных
- Есть стабильный интернет
- Нужна резервная копия данных

### Используйте локальную версию если:
- Работаете офлайн
- Важна приватность данных
- Нужна максимальная скорость
- Одно устройство
