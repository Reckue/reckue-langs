# Установка и использование API версии плагина

## 🚀 Быстрый старт

### 1. Сборка API версии
```bash
npm run build:api
```

### 2. Установка в браузер
1. Откройте Chrome Extensions: `chrome://extensions/`
2. Включите "Developer mode" (правый верхний угол)
3. Нажмите "Load unpacked"
4. Выберите папку с проектом

### 3. Проверка работы
1. Откройте любую веб-страницу
2. Нажмите на иконку расширения
3. Проверьте, что словари загружаются с сервера

## 🔄 Переключение между версиями

### Переключение на API версию
```bash
./switch-to-api.sh
```

### Возврат к локальной версии
```bash
./switch-to-local.sh
```

## 📋 Что изменилось

### ✅ Новые возможности
- **Автоматическая авторизация** через temp-in
- **Синхронизация словарей** с сервером
- **Сохранение прогресса** в облаке
- **Мультиустройственная поддержка**

### 🔧 Технические изменения
- Добавлен `ApiService` для работы с API
- Создан `ApiWordbookService` для синхронизации
- Адаптированы все основные компоненты
- Добавлен fallback на локальное хранение

### 📊 API Endpoints
- `POST /api/1/auth/tempin` - авторизация
- `GET /api/1/wordbooks` - словари
- `POST /api/1/wordbook/words` - слова
- `GET /api/1/auth/whoami` - пользователь

## 🛠️ Разработка

### Структура файлов
```
src/
├── core/
│   ├── api/
│   │   └── ApiService.js          # Основной API сервис
│   ├── words/
│   │   └── ApiWordbookService.js  # API словари
│   └── ApiStore.js                # API хранилище
├── page/
│   └── ApiPageService.ts          # API страница
├── popup/
│   └── ApiPopupService.js         # API попап
└── api-page.ts                    # Точка входа страницы
    └── api-popup.ts               # Точка входа попапа
```

### Добавление новых функций
1. Добавьте метод в `ApiService`
2. Обновите `ApiWordbookService` при необходимости
3. Протестируйте с реальным API

## ⚠️ Известные ограничения

### Сетевые проблемы
- При недоступности API используется локальный режим
- Автоматические повторные попытки подключения
- Graceful degradation

### Совместимость
- Сохранена совместимость с существующим интерфейсом
- Плавный переход между режимами
- Обратная совместимость

## 🆘 Устранение неполадок

### Проблемы с авторизацией
1. Проверьте подключение к интернету
2. Убедитесь, что API доступен
3. Очистите localStorage и перезапустите

### Проблемы с синхронизацией
1. Проверьте консоль на ошибки
2. Убедитесь в правильности токена
3. Попробуйте переустановить расширение

### Проблемы со сборкой
1. Убедитесь, что все зависимости установлены
2. Проверьте версию Node.js (>=14)
3. Очистите кэш webpack

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи в консоли браузера
2. Убедитесь в доступности API
3. Попробуйте переключиться на локальную версию
4. Создайте issue в репозитории
