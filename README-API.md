# Reckue Languages Plugin - API Version

Это адаптированная версия плагина Reckue Languages, которая работает с API reckue.com вместо локального localStorage.

## Основные изменения

### 🔐 Авторизация через API
- Автоматическая авторизация через `/api/1/auth/tempin`
- Сохранение токена в localStorage
- Автоматическое обновление токена при истечении

### 📚 Синхронизация словарей
- Загрузка словарей с сервера
- Синхронизация изменений в реальном времени
- Поддержка основного словаря пользователя

### 🔄 Совместимость
- Сохранена совместимость с существующим интерфейсом
- Fallback на локальное хранение при недоступности API
- Плавный переход между режимами

## Архитектура

### Новые компоненты

#### `ApiService` (`src/core/api/ApiService.js`)
Основной сервис для работы с API:
- Авторизация через temp-in
- CRUD операции со словарями
- Управление токенами

#### `ApiWordbookService` (`src/core/words/ApiWordbookService.js`)
Адаптированный сервис словарей:
- Загрузка слов из API
- Синхронизация с локальным кэшем
- Совместимость с существующим интерфейсом

#### `ApiStore` (`src/core/ApiStore.js`)
Адаптированный Store:
- Проверка авторизации
- Совместимость с существующими настройками

### Адаптированные компоненты

#### `ApiApp` (`src/core/ApiApp.js`)
- Инициализация API сервиса
- Асинхронная загрузка данных

#### `ApiPageService` (`src/page/ApiPageService.ts`)
- Проверка доступности API
- Fallback на локальный режим

#### `ApiPopupService` (`src/popup/ApiPopupService.js`)
- Отображение статуса API
- Информация о пользователе

## Конфигурация

### API Endpoints
Все API вызовы направляются на `https://api.reckue.com/api/1/`

### Авторизация
- Автоматическая авторизация через temp-in
- Токен сохраняется в localStorage как `reckue_temp_token`
- Автоматическое обновление при истечении

### Словари
- Используется основной словарь пользователя
- Автоматическое создание словаря при первом использовании
- Поддержка пагинации при загрузке слов

## API Endpoints

### Авторизация
- `POST /api/1/auth/tempin` - временная авторизация
- `GET /api/1/auth/whoami` - информация о пользователе

### Словари
- `GET /api/1/wordbooks` - все словари пользователя
- `GET /api/1/wordbooks/main` - основной словарь
- `POST /api/1/wordbooks` - создание словаря

### Слова
- `POST /api/1/wordbook/words/{wordbookId}` - получение слов
- `POST /api/1/wordbook/words` - добавление слова
- `POST /api/1/wordbook/words/list` - добавление списка слов
- `POST /api/1/wordbook/words/levels` - обновление уровня
- `DELETE /api/1/wordbook/words` - удаление слова
